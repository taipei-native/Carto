# Update checklist

1. Prepare an update press release (English, Chinese optional)
2. Create a pull request to merge `dev` branch to `main`
3. Publish the project to Paradox Mods
4. Verify the Paradox Mods version is correct
5. Approve the pull request
6. Push wiki repo \
   *Take screenshots* \
   *Compress images* \
   *Commit to `wip`* \
   *Merge `wip` to `main`*
7. Send press release

## The patch changelog template

```md
## j.n.p Changelog
-# 20xx-xx-xx
* Did something. [Soggested by someone]
* Fixed something. [Reported by anonymous]
```

